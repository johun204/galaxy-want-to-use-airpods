개인 사용 목적의 포크입니다. **배터리 소모 최소화**가 최우선이고, 나머지는 갤럭시 루틴으로 필요할 때만 불러 쓰는 구조입니다.

## 주요 기능

### 배터리 다이나믹 아일랜드
에어팟이 연결되면(또는 바로가기·타일을 실행하면) 화면 상단에 에어팟 그림 + 좌/우/케이스 배터리가 담긴 검은 알약이 떴다가 사라집니다.

- 상단 중앙(펀치홀 카메라)에서 빠르게 커졌다가 다시 그쪽으로 모이며 사라짐
- 카메라가 알약의 검은 여백에 들어앉도록 위쪽 여백을 두고 배치
- 표시 시간은 설정에서 2 / 3 / 5 / 10초 선택 (기본 3초)
- 탭하면 앱이 열리고, 화면이 꺼져 있으면 띄우지 않음
- `다른 앱 위에 표시` 권한이 필요하며 앱 첫 실행 시 한 번 안내

### 온디맨드 모드 (기본 켜짐)
백그라운드 상주를 없앤 모드입니다.

- 에어팟 연결 → 서비스가 몇 초 뜸 → 알림/아일랜드 1회 표시 → **서비스 완전 종료**
- 이후 배터리는 재연결 / 바로가기(갤럭시 루틴) / 앱·위젯 열 때만 다시 읽습니다
- 상주 알림과 주기적 스캔이 동작하지 않으므로 대기 소모가 사실상 0입니다
- 마지막으로 읽은 배터리 값은 위젯과 앱 화면에 그대로 남습니다

끄면 기존 동작(상주 알림 + 듀티 사이클 스캔)으로 돌아갑니다.

### 갤럭시 루틴 연동 (앱 바로가기)
홈 화면에서 앱 아이콘을 꾹 누르면 나오는 두 개의 바로가기입니다. 갤럭시(빅스비) 루틴의 **앱 열기 → 바로가기** 에서 그대로 선택할 수 있습니다.

| 바로가기 | 동작 |
|---|---|
| 배터리 다이나믹 아일랜드 | 상단 아일랜드로 배터리 표시 |
| 배터리 알림 | 알림으로 배터리 표시 |

예: *이어폰 연결됨* → *배터리 다이나믹 아일랜드*, 또는 *운동 시작* → *배터리 알림*.
빠른 설정 타일(`에어팟 배터리`)로도 같은 동작을 부를 수 있습니다.

> 루틴이 바로가기를 실행하면 잠깐 다른 액티비티가 뜨는 구조라, 앱을 열어 둔 상태에서는 화면이 전환될 수 있습니다. 연결 시 표시만 원한다면 루틴 대신 `에어팟 연결 시 자동 표시`를 쓰는 편이 낫습니다 — 액티비티를 전혀 띄우지 않고, 배터리 소모도 동일합니다(상주 없는 브로드캐스트 수신).

**루틴으로만 쓸 때의 최적화**: 설정에서 `에어팟 연결 시 자동 표시`를 끄면 앱이 블루투스 연결 브로드캐스트 수신 자체를 그만둡니다(수신 컴포넌트를 비활성화). 다른 블루투스 기기가 연결될 때도 앱이 깨어나지 않아, 루틴이 부를 때만 동작합니다. 온디맨드 모드에선 부팅 시에도 뜨지 않습니다.

### 그 밖의 포크 변경점
- BLE 비콘 + AACP(L2CAP 제어 채널) 양쪽에서 배터리 수신, 제어 채널 값 우선
- 노이즈 컨트롤 / 귀 감지 등 에어팟 설정 제어
- 배터리 링이 그려진 일러스트, 위젯 3종(1x1 / 2x2 / 4x1), 내 에어팟 찾기(신호 세기)
- 듀티 사이클 스캔, 화면 꺼짐/잠금 시 스캔 절전, 갱신 주기 선택(5초~5분)
- 제어 채널에서 배터리를 받으면 진행 중인 BLE 스캔을 즉시 중단, 최근 값이 있으면 스캔 없이 바로 표시
- 한국어 UI

### 권한
설정 화면의 각 옵션에는 필요한 권한이 함께 표시되고, 권한이 없으면 옵션을 켤 수 없습니다(켜려고 하면 해당 권한 화면으로 이동).

| 옵션 | 필요 권한 |
|---|---|
| 상태 표시 알림 / 착용 시 배터리 알림 | 알림 |
| 배터리 다이나믹 아일랜드 | 다른 앱 위에 표시 |
| 에어팟 연결 시 자동 표시 / 스캔 절전 / 연결 직후 고속 스캔 / 제어 채널 | 근처 기기 |

근처 기기 권한을 거부한 상태로는 배터리를 전혀 읽을 수 없어, 앱을 열면 권한 안내가 뜹니다.

```
./gradlew assembleRelease
```
`local.properties` 에 `sdk.dir` 만 잡혀 있으면 됩니다. (JDK 17, compileSdk 36)
